# 画像ファイルについて

このディレクトリには、チャットボットで使用する画像ファイルを配置してください。

## 必要な画像

### receptionist.png（静止画）
- 受付嬢のアイコン画像（静止画）
- 推奨サイズ: 200x200px以上
- 形式: PNG、JPG、WEBP
- 用途: 通常時の表示（会話メッセージ、見積もり明細など）

### receptionist.gif（アニメーション）
- 受付嬢のアニメーション画像
- 推奨サイズ: 200x200px以上
- 形式: GIF（アニメーション）
- 用途: ボットが返答を考えている時（タイピングインジケータ表示中）

## 動作仕様

- **返答中（タイピング中）**: `receptionist.gif` を表示（アニメーション）
- **通常時（メッセージ表示時）**: `receptionist.png` を表示（静止画）

画像が配置されていない場合は、デフォルトのアイコンが表示されます。

## フォールバック

1. `receptionist.gif` が見つからない場合 → `receptionist.png` を表示
2. `receptionist.png` が見つからない場合 → デフォルトアイコン（👩‍💼）を表示
