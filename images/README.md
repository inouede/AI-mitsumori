# 画像ファイルについて

このディレクトリには、チャットボットで使用する画像ファイルを配置してください。

## 必要な画像

### img.png（静止画）
- 受付嬢のアイコン画像（静止画）
- 推奨サイズ: 200x200px以上
- 形式: PNG、JPG、WEBP
- 用途: 通常時の表示（会話メッセージ、見積もり明細など）

### mov.png（アニメーション）
- 受付嬢のアニメーション画像
- 推奨サイズ: 200x200px以上
- 形式: PNG（アニメーション）
- 用途: ボットが返答を考えている時（タイピングアニメーション表示中）

## 動作仕様

- **返答中（タイピング中）**: `mov.png` を表示（アニメーション）
- **通常時（メッセージ表示時）**: `img.png` を表示（静止画）

画像が配置されていない場合は、デフォルトのアイコンが表示されます。

## フォールバック

1. `mov.png` が見つからない場合 → `img.png` を表示
2. `img.png` が見つからない場合 → デフォルトアイコン（👩‍💼）を表示
