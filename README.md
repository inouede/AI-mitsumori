# AIチャットボット機能付き自動見積もりシステム

LINEのような会話形式でリフォームの見積もりを自動生成するシステムです。

## 特徴

- LINEライクな吹き出しチャットUI
- AIが質問しながら見積もりを自動作成
- わからない質問は自動で別の質問に変更
- 合計金額を目立つ形で表示
- 電話番号・メールアドレスのワンクリック連絡
- スマートフォン対応
- FTPサーバーにアップロードするだけで動作

## 必要な環境

- PHP 7.0以上（curl拡張機能が必要）
- FTPサーバー（PHPが動作する環境）
- Claude API キー

## セットアップ手順

### 1. ファイルのアップロード

すべてのファイルをFTPサーバーにアップロードします。

```
/
├── index.html
├── style.css
├── script.js
├── api.php
├── config.sample.php
└── README.md
```

### 2. Claude API キーの取得

1. [Anthropic Console](https://console.anthropic.com/) にアクセス
2. アカウント作成 or ログイン
3. API Keysセクションから新しいAPIキーを作成
4. APIキーをコピー（sk-ant-api03-で始まる文字列）

### 3. 設定ファイルの作成

サーバー上で以下のコマンドを実行するか、FTPクライアントで操作します：

```bash
cp config.sample.php config.php
```

`config.php`を編集して、Claude API キーを設定します：

```php
$CLAUDE_API_KEY = 'sk-ant-api03-あなたのAPIキー';
```

### 4. 会社情報の設定

`index.html`を開いて、会社の電話番号とメールアドレスを編集します：

```html
<a href="tel:0120-XXX-XXXX" class="contact-link phone-link">
    <span class="icon">📞</span>
    <span>0120-XXX-XXXX</span>  <!-- ここを変更 -->
</a>
<a href="mailto:info@example.com" class="contact-link email-link">
    <span class="icon">✉️</span>
    <span>info@example.com</span>  <!-- ここを変更 -->
</a>
```

### 5. ファイルのパーミッション設定

PHPファイルが実行できるようにパーミッションを設定します：

```bash
chmod 644 index.html
chmod 644 style.css
chmod 644 script.js
chmod 644 api.php
chmod 600 config.php  # セキュリティのため読み取り専用に
```

### 6. 動作確認

ブラウザで `https://あなたのドメイン/index.html` にアクセスして動作を確認します。

## 使い方

1. チャットで「トイレを交換したい」などのリフォーム内容を入力
2. AIが質問してくるので答えていく
3. 自動的に見積もりが計算されて表示される
4. 電話番号やメールアドレスをクリックして問い合わせ可能

## AIモデルの選択

`api.php`の中でClaudeのモデルを変更できます（api.php:162）：

### 利用可能なモデル（2025年1月時点）

| モデル名 | 性能 | 速度 | コスト | 推奨用途 |
|---------|------|------|--------|----------|
| `claude-sonnet-4-5-20250929` | ★★★★★ | ★★★★☆ | 高 | **最新・最高性能（推奨）** |
| `claude-3-5-sonnet-20240620` | ★★★★☆ | ★★★★☆ | 中 | バランス重視 |
| `claude-3-haiku-20240307` | ★★★☆☆ | ★★★★★ | 低 | 高速・低コスト |

**デフォルト**: `claude-sonnet-4-5-20250929` （Claude Sonnet 4.5 - 2025年9月リリース）

### モデルの変更方法

`api.php`の約162行目を編集：

```php
$requestBody = [
    'model' => 'claude-sonnet-4-5-20250929',  // ここを変更
    'max_tokens' => 2048,
    'system' => $systemPrompt,
    'messages' => $messages
];
```

### モデル404エラーが出る場合

一部のAPIキーは最新モデルにアクセスできない場合があります。その場合は以下を試してください：

1. **claude-3-5-sonnet-20240620** に変更（2024年6月版）
2. **claude-3-haiku-20240307** に変更（確実に動作）

```php
'model' => 'claude-3-haiku-20240307',  // 確実に動作
```

## トラブルシューティング

### エラーメッセージが表示される場合

システムは詳細なエラーメッセージを表示するように設計されています。エラーが発生した場合：

1. **ブラウザの開発者ツールを開く**（F12キー）
2. **コンソールタブ**を確認して、`[DEBUG]`で始まるログを確認
3. エラーメッセージの内容を確認

### よくあるエラーと対処法

#### 「Claude APIキーが設定されていません」

**原因**: `config.php`が存在しないか、APIキーが設定されていない

**対処法**:
1. `config.sample.php`を`config.php`にコピー
2. `config.php`を開いて、以下の行を編集：
   ```php
   $CLAUDE_API_KEY = 'sk-ant-api03-あなたの実際のAPIキー';
   ```
3. APIキーは [Anthropic Console](https://console.anthropic.com/) で取得

#### 「APIキーが無効です」（HTTP 401エラー）

**原因**: Claude APIキーが間違っているか期限切れ

**対処法**:
1. [Anthropic Console](https://console.anthropic.com/) にログイン
2. APIキーが正しいか確認
3. 必要に応じて新しいAPIキーを生成
4. `config.php`のAPIキーを更新

#### 「Claude API Error (HTTP 404): model: xxx」

**原因**: 使用しているモデル名が存在しないか、APIキーがアクセスできない

**対処法**:
1. `api.php`の162行目付近でモデル名を確認
2. 最新モデル（Claude Sonnet 4.5）にアクセスできない場合は、以下に変更：
   ```php
   'model' => 'claude-3-5-sonnet-20240620',  // または
   'model' => 'claude-3-haiku-20240307',     // 確実に動作
   ```
3. 詳しくは「AIモデルの選択」セクションを参照

#### 「申し訳ございません。エラーが発生しました」

**原因**: さまざまな理由が考えられる

**対処法**:
1. ブラウザのコンソール（F12）を開く
2. エラーの詳細メッセージを確認
3. `[DEBUG] APIレスポンスデータ:`のログを確認
4. エラーメッセージに応じて対処：
   - APIキー関連 → `config.php`を確認
   - ネットワークエラー → サーバーの接続を確認
   - その他 → サーバーのPHPエラーログを確認

#### 「通信エラーが発生しました」

**原因**: サーバーとの通信に失敗

**対処法**:
1. インターネット接続を確認
2. `api.php`に直接アクセスして動作を確認
3. サーバーのファイアウォール設定を確認
4. PHPのcurl拡張機能が有効か確認：
   ```bash
   php -m | grep curl
   ```

### デバッグモード

`script.js`の先頭にデバッグモードの設定があります：

```javascript
const DEBUG_MODE = true;  // デバッグ情報をコンソールに出力
```

本番環境では`false`に設定することで、コンソールログを無効化できます。

### 開発者ツールでのデバッグ

1. ブラウザでF12キーを押して開発者ツールを開く
2. **コンソール**タブで以下の情報を確認：
   - `[DEBUG] ユーザーメッセージ:` - 送信したメッセージ
   - `[DEBUG] APIリクエスト:` - APIに送信するデータ
   - `[DEBUG] APIレスポンスステータス:` - APIのHTTPステータス
   - `[DEBUG] APIレスポンスデータ:` - APIからの返答
   - `[DEBUG] 見積もり情報を更新:` - 見積もりデータ
3. **ネットワーク**タブで`api.php`へのリクエストを確認

### チャットが全く動作しない

1. ブラウザの開発者ツール（F12）でエラーを確認
2. `api.php`に直接アクセスしてPHPが動作しているか確認
3. サーバーのPHPバージョンを確認（7.0以上が必要）：
   ```bash
   php -v
   ```
4. curl拡張機能が有効か確認

### 見積もりが表示されない

1. Claude APIキーが正しく設定されているか確認
2. APIの利用制限に達していないか確認
3. サーバーから外部API（api.anthropic.com）への接続が許可されているか確認
4. ブラウザのコンソールで`[DEBUG] 見積もり情報を更新:`のログを確認

## セキュリティ注意事項

- `config.php`は必ず`.gitignore`に追加してください
- APIキーは絶対に公開しないでください
- 本番環境では必ずHTTPS接続を使用してください
